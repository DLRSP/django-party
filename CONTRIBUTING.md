# Contributing

Issues and pull requests are welcome on [GitHub](https://github.com/DLRSP/django-party).

1. Fork and clone the repository.
2. Create a virtualenv and `pip install -e ".[testing]"`.
3. Run `python runtests.py` (or `pytest --ds=tests.settings`).
4. Open a PR against `main`.

Please keep code, comments, identifiers, and commit messages in English.
User-visible Italian (or other locales) belongs only in gettext catalogs.
